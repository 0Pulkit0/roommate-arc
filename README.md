# Roommate Arc

A small website that reviews popular anime characters as if they were roommates.
I made it for my web development end-term project using HTML and CSS.

## Pages
- index.html - home page
- roommates.html - the character reviews
- rules.html - house rules
- starter-kit.html - a packing checklist and some questions to sort out before moving in
- about.html - about me and credits

## How to run it
Open index.html in any web browser. All the pages are linked through the
navigation bar at the top.
