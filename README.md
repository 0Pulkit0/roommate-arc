# Roommate Arc

A small website that reviews popular anime characters as if they were roommates.
I made it for my web development end-term project using HTML, CSS and a little bit
of JavaScript.

## Pages
- index.html - home page
- roommates.html - the six character reviews
- rules.html - house rules
- starter-kit.html - a packing checklist that remembers your ticks
- about.html - about me and credits

## How to run it
Open index.html in any web browser. All the pages are linked through the
navigation bar at the top. The starter kit page uses a short JavaScript file
(script.js) to save your checklist ticks in the browser.
